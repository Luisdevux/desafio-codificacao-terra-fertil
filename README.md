# Desafio de Codificação - Projeto Terra Fértil (IFRO)

Solução desenvolvida para a seleção de bolsistas do Projeto Terra Fértil (Edital nº 96/2026/REIT - CGAB/IFRO) na função de Desenvolvedor Técnico Júnior.

Implementação em TypeScript do algoritmo de rateio proporcional de mudas com cotas máximas, saturação iterativa e critérios de desempate.

## Tecnologias
- TypeScript
- Vitest
- Node.js

## Como Executar

Instale as dependências:
```bash
npm install
```

Execute a suíte de testes:
```bash
npm test
```

Para executar os testes em modo interativo (watch):
```bash
npm run test:watch
```
